# **🍰 Gestionnaire de Recettes (CRUD)**

Ce projet est une application web dynamique que j'ai conçue pour apprendre à gérer une base de données de A à Z. C'est un outil qui permet d'organiser un catalogue culinaire de manière simple et sécurisée.

### **🎯 L'objectif**
L'idée était de créer une interface "Admin" où l'on peut ajouter, modifier ou supprimer des recettes (le fameux système CRUD) tout en ayant une partie publique élégante pour consulter les plats.

### **🛠️ Pourquoi ces technos ?**
* **PHP Natif & PDO** : J'ai choisi de ne pas utiliser de framework pour bien comprendre comment les données circulent entre les formulaires et la base de données MySQL.
* **Sécurité** : J'ai mis en place un système de sessions pour l'administration et le hachage des mots de passe (`password_hash`) pour protéger l'accès.
* **CSS moderne** : Utilisation de **Flexbox** et **Grid** pour que l'affichage des recettes soit propre et s'adapte à tous les écrans.

### **🌟 Ce que j'ai appris**
Ce projet m'a permis de solidifier mes bases en Backend et de mieux comprendre la logique des données, le tout en m'amusant étant passionnée de cuisine !"
